 

# GNSS Antenna



## Overview

The Kalmix Scout Pro features a built-in high gain ceramic patch antenna designed for multi-frequency and multi-constellation global navigation satellite system (GNSS) applications.



![Type-C 12P Plug Drawing](/img/hardware/antenna_1.png)



## Specifications

### Antenna Dimensions

Built-in high gain ceramic patch antenna, available in two size options:

- **33mm × 33mm × 6mm**
- **25mm × 25mm × 4mm**

### Antenna Characteristics

| Parameter    | Specification         |
| ------------ | --------------------- |
| Type         | Ceramic Patch Antenna |
| Gain         | High gain design      |
| Installation | Built-in integrated   |



### Frequency Point Support

The ceramic antenna supports the following frequency points:

| Band    | Frequency Points        |
| ------- | ----------------------- |
| GPS     | L1C/A, L5               |
| GLONASS | L1                      |
| Galileo | E1, E5a                 |
| BDS     | B1I, B1C, B2I, B2a, B2b |
| QZSS    | L1C/A, L5               |
| SBAS    | L1                      |



### Frequency Range Support

The ceramic antenna supports the following frequency range:

| Frequency Points |
| ---------------- |
| 1559-1606 MHz    |
| 1197-1249 MHz    |



### Environmental Specifications

#### Operating Environment

| Parameter                           | Specification   |
| ----------------------------------- | --------------- |
| Working Temperature                 | -40°C to +85°C  |
| Shell and Cable Working Temperature | -40°C to +105°C |
| Storage Temperature                 | -40°C to +90°C  |
| Humidity                            | ≤95%            |
| IP Rating                           | IP67            |



## Usage Precautions

:::warning Important
Please do not expose the antenna to sun for a long time to avoid damage to internal precision circuits.
:::

:::caution Signal Reception
When inside buildings, tunnels or near large obstacles, the antenna signal reception may be affected and positioning capability may be reduced.
:::
